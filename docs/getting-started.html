Getting started

Install Hushpen, allow it to hear and paste, and make your first dictation. Everything stays on your computer.

Install

Download a file from the release page. Hushpen runs on macOS 13 or later on Apple silicon, and on Linux x64 and arm64 with an X11 session.

platform what to do
macOS Open Hushpen-2.2.0-macos-arm64.dmg and drag Hushpen to Applications. Or unzip Hushpen-2.2.0-macos-arm64.zip and move Hushpen.app to Applications.
Linux AppImage Run chmod +x Hushpen-2.2.0-linux-x64.AppImage, then run the file.
Debian, Ubuntu sudo apt install ./Hushpen-2.2.0-linux-x64.deb
Fedora, openSUSE sudo dnf install ./Hushpen-2.2.0-linux-x64.rpm
Linux tar.gz Run tar xzf Hushpen-2.2.0-linux-x64.tar.gz, then run hushpen from the new folder.

On an Arm machine, replace x64 with arm64 in the Linux file names.

macOS first start

The app is signed with a Developer ID certificate and notarized by Apple, so macOS opens it after one standard confirmation.

Linux requirements

  • An X11 session. On Wayland the global key and paste show "not available".
  • A Vulkan or OpenGL driver. On Debian and Ubuntu, mesa-vulkan-drivers or libgl1-mesa-dri is enough. A machine with no driver cannot open the window.
  • A system tray host if you want the tray icon (StatusNotifier, which most desktops include).

You can also build Hushpen from source. The steps are in the README.

macOS permissions

Hushpen asks for three permissions in its first-run setup. Each row has Allow and Open Settings buttons, and the status updates live.

permission used for
Microphone Recording your voice
Input Monitoring Seeing the hold key while you use other apps
Accessibility Pasting the text into the focused app

Hushpen adds itself to the matching lists in System Settings when it starts, and its stable signature keeps your grants across updates and reinstalls. On macOS 27, the Accessibility switch also covers Input Monitoring.

Grant them again

macOS forgets the grants only when the signing certificate changes, or when you remove them yourself. Hushpen notices at start and opens the setup step again.

  • Open the setup step (it opens by itself), or System Settings > Privacy & Security.
  • For each of the three permissions, select Hushpen and remove it with the minus button if it is listed. Then press Allow in Hushpen.
  • If a row stays stuck, reset it in Terminal and press Allow again:
tccutil reset Microphone io.github.surajmandalcell.hushpen
tccutil reset ListenEvent io.github.surajmandalcell.hushpen
tccutil reset Accessibility io.github.surajmandalcell.hushpen

First dictation

The first start opens a five-step setup:

  • Permissions: each line shows where a system need stands
  • Microphone test: press Test, say a sentence, then press Stop to see the level move
  • Speech model: download one Whisper model. Hushpen checks the file before it uses it.
  • Shortcut practice: hold the hold key, say a sentence, then let go
  • Updates: the update check is off unless you turn it on, and you can change it later in Settings

After setup, dictate into any app:

  • click where you want the text
  • hold Right Option on macOS or Right Alt on Linux, and speak
  • let go to finish. Hushpen cleans up the text and pastes it. Press Esc to cancel.

The flow bar shows the dictation state without taking focus. To use another key, record it in the Shortcuts section of Settings. Any key or chord works. If another app already uses it, the field says how to free it. The switch on each row turns that shortcut off, and the reset button brings back its default. Select text in any app and press Ctrl+Cmd+S (Ctrl+Alt+S on Linux) to hear it read aloud; press it again to stop. Settings is one list with a search field: press Cmd+F (Ctrl+F on Linux) and type to find a setting. Home also has a Record button and a language choice. If your microphone is quiet, raise Input boost in the Audio section of Settings, up to 200%.

The Models view lists speech, text cleanup, and voice models, and marks the recommended one of each kind. The details button of a model shows what it is good for, its speed, accuracy, memory, and languages, the page it downloads from, its folder, and its checksum. A download starts only when the disk has room for it.

Your data

Hushpen keeps its settings, history database, downloaded models, saved dictation audio, and logs in one data folder. Move it in the Storage section of Settings.

system data folder
macOS ~/Library/Application Support/Hushpen
Linux $XDG_DATA_HOME/hushpen, or ~/.local/share/hushpen when XDG_DATA_HOME is not set

Hushpen sends no telemetry. It uses the network only for model downloads you start, the update check if you turn it on, and an AI cleanup endpoint if you set one.
