Speech to text benchmark across dictation apps and models.

36 TED talk clips, 19 English accents, scored word by word against the talks' human-made captions. Every app and model ran with its default settings on the same Mac. Hushpen Whisper Turbo got the most words right. FluidVoice Parakeet v3 was the fastest.

Last run 19 November 2026. Apple M4 Pro, 24 GB, macOS. Nothing was tuned on these clips.

  • 95.0words right out of 100 for Hushpen Whisper Turbo, the most accurate.
  • 0.37 sfor 1 minute of audio with FluidVoice Parakeet v3, the fastest on this Mac.
  • 2.4xFluidVoice runs Parakeet v3 this much faster than Hushpen with the same model, at the same accuracy.

How the test was run.

Nothing was tuned on these clips. Every app and model ran once per clip with its default settings: no custom words, no prompt, and no best-of picks.

Method
Clips36 scored clips from TED talks, 25 to 30 s each, about 1 minute into each talk, with no laughter or applause inside. The full list with links is below. No audio is published.
Accents19 English accents, 2 speakers each. Filipino has one speaker. Russian has one scored speaker: on Evgeny Morozov's talk the captions run about 5 s ahead of the sound, so that clip was transcribed but not scored.
Truth textThe talks' human-made English captions. Auto captions were never used. Each clip starts and ends on caption edges. The captions leave out some "uh"s and repeated words, so every model loses a few points for words the speaker really said.
ScoreBoth sides go through the Whisper English text normalizer (lowercase, no punctuation, numbers and spellings made the same, fillers such as "um" removed). Then word error rate with jiwer over all words. Words right is 100 minus the word error rate.
SpeedMedian of 3 runs for each length, with the model loaded. Model load is timed apart.
This MacApple M4 Pro, 14 cores, 24 GB, macOS. Metal GPU on for every app.
Linux machinesHushpen only, CPU only, 3 threads: two Arm Neoverse-N1 servers with 4 cores, and an AMD Ryzen 3 2200G desktop with 4 cores. Accuracy there came out within 1 point of the Mac.
HushpenBuilt from master on 19 November 2026. A small bench program calls Hushpen's own speech loader and transcribe call with the app's defaults: Silero speech detection, Auto threads, language Detect. Nemotron Unified ran through the live text engine with the recording fed in as fast as possible.
FluidVoice 1.6.13The installed app's local API: a WAV file sent to POST /v1/transcribe on loopback. Default model, Parakeet TDT v3 (Multilingual).
Handy 0.10.1The official Apple silicon release, command line --transcribe-file, built-in transcribe-cpp on Metal. Model Parakeet Unified English 0.6B Q8_0, the first choice in its English catalog.
VoiceInk 2.27Not measured. Its file queue needs Start pressed in the app window, and opening a file brings the app to the front, so it cannot run unattended.
MacWhisper 15.11Not measured. The free install had no model, its command line tool answered "No model selected", and a model is installed from the app window.
Other appsSuperwhisper, Wispr Flow, Aqua Voice, Willow Voice and Spokenly were not tested in this round. Their claims are listed above.
